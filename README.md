# tg-digest — дайджест Telegram-каналов

В заданные часы (по умолчанию 9:00, 14:00, 20:00 MSK) Worker `tg-digest` на Cloudflare читает новые посты публичных
каналов из ленты `t.me/s/<канал>`, Gemini пишет из них дайджест, бот публикует его в канал.
Список каналов — папка Telegram «Bot»: раз в сутки `sync_channels.py` на этой машине читает её вашим
аккаунтом и кладёт юзернеймы в KV. Машина выключена — дайджесты идут по старому списку.

| Файл | Что |
|---|---|
| `worker.js` | Worker: сбор, Gemini, публикация; ежечасный cron, команды бота (webhook `/tg`), `GET /run?key=<ADMIN_KEY>[&dry=1]`, `POST /notify?key=` (сообщение владельцу), проверка портов семейных прокси (стенд и GCP) |
| `sync_channels.py` | папка «Bot» → KV `channels` (Telethon, venv `~/.venvs/tg-digest`) |
| `deploy.sh` | выкладка через REST Cloudflare: KV, скрипт, секреты, cron; webhook и меню команд бота |
| `test/test_parse.mjs` | `node test/test_parse.mjs` — разбор ленты, листание, разбивка |

Настройки и секреты — секрет `tg-digest` в Bitwarden Secrets Manager (`secret tg-digest`); ключ Gemini — секрет `agy`;
сессия Telegram — `~/.config/tg-digest/digest.session` (600, это доступ к аккаунту).

KV `DIGEST`: `channels` — список юзернеймов, `last` — `{канал: id последнего поста в дайджесте}`,
`background`, `tech` — источники уровней мир и тех, `pool` — собранное за сутки,
`settings` — `{hours, paused, focus}`, `status` — итог прошлого выпуска, `update_id` — защита от повторной доставки.

## Команды бота (@Nick_ai_bot)

Слушается только владельца (`OWNER_ID`), остальным молчит. В группе бот видит только команды;
переслать пост из канала, чтобы добавить его, — в личку боту.

`/list`, `/add @канал …`, `/add мир|тех @канал|URL-RSS …`, `/del @канал …`, `/now`, `/preview`, `/status`, `/pause`, `/resume`,
`/schedule 9 14 20`, `/alerts on|off`, `/focus текст` (`/focus -` — сброс), `/ask вопрос` (по постам за сутки), `/help`.
`last` сдвигается только после успешной публикации: упал запуск — следующий подберёт те же посты.

Закрытые каналы и группы из папки пропускаются — их лента без входа не открывается.

## Источники и пул

Три уровня: свои (`channels`, [мой]), мир (`background`, [мир]: 8 агентств на русском + RSS BBC World,
Guardian World, Al Jazeera, NYT World) и технологии (`tech`, [тех]: Хабр, Data Secrets, «в IT», Эксплойт,
AI для Всех + RSS Ars Technica, TechCrunch, MIT Technology Review, Хабр-лучшее, CNews).

Каждые 15 минут Worker собирает новое из всех источников в KV `pool` (по странице на источник, своим — до двух;
не больше 40 подзапросов — лимит бесплатного Workers 50). В часы выпуска Gemini пишет дайджест из
неопубликованного: «🌍 Главное в мире» из [мир], «🚀 Технологии и ИИ» из [тех], остальное — рубриками
по своим каналам. Без новых постов своих каналов выпуск не выходит. Опубликованное лежит в пуле сутки —
по нему отвечает `/ask`, без запросов к источникам.

## Экстренное 🚨

После каждого сбора лёгкая модель (`gemini-flash-lite-latest`) смотрит материалы за 2 часа и решает, есть ли
чрезвычайное: война, массовый теракт или катастрофа, ядерный инцидент, смена власти, обвал рынков. Порог
высокий, продолжение идущих конфликтов и заявления — не тревога. Нужны минимум два разных источника —
это проверяет код, а не только модель; ссылки берутся только из пула. Объявленное помнится 48 часов
(KV `alerts`) и не повторяется. В четверть часа выпуска проверки нет — её сделает следующий сбор.
