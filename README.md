# tg-digest — дайджест Telegram-каналов и RSS

Бот собирает новые посты публичных Telegram-каналов (лента `t.me/s/<канал>`) и RSS-ленты, по расписанию
Gemini пишет из них дайджест, бот публикует его в группу или канал. Управление — командами бота в личке.

## Как устроено

```
ВМ (systemd tg-digest)                       Cloudflare
  node local.mjs ──────────── R2 REST ──────▶ бакет tg-digest (состояние)
   ├─ каждые 15 мин: сбор → пул, проверка 🚨
   ├─ в часы выпуска: Gemini → дайджест → группа
   └─ long polling: команды бота
```

- `worker.js` — весь код дайджеста: сбор, пул, Gemini, публикация, тревоги, команды бота. Написан как
  Cloudflare Worker, но по расписанию его исполняет `local.mjs`.
- `local.mjs` — исполнитель на ВМ: подставляет R2 через REST API Cloudflare, вызывает `scheduled` на границах
  четверти часа, забирает команды бота long polling'ом. `node local.mjs run` — разовый выпуск и выход.
- На Cloudflare — только бакет R2 с состоянием. Уведомления о прокси — отдельный проект tg_proxy_check.

Почему не всё на Cloudflare: бесплатный Workers ограничивает вызов 10 мс CPU, а сбор с разбором лент тратит
около 90 мс. Платный тариф ($5/мес) снял бы ограничение; здесь вместо него — бесплатная ВМ.

| Файл | Что |
|---|---|
| `worker.js` | код дайджеста |
| `local.mjs` | исполнитель на ВМ |
| `deploy.sh` | выкладка: бакет R2, меню команд бота; на ВМ — код, `/etc/tg-digest.env`, systemd-юнит |
| `test/test_parse.mjs` | `node test/test_parse.mjs` — разбор ленты и RSS, листание, разбивка, команды |

## Что нужно для своей копии

- аккаунт Cloudflare: R2 (бесплатно), API-токен с правом R2 Edit;
- ВМ с Node 18+ и systemd, вход по ssh с правом sudo (подойдёт e2-micro из бесплатного тарифа GCP);
- бот Telegram (токен от @BotFather), группа или канал для выпусков, где бот — участник с правом писать;
- ключ Gemini API.

Настройки `deploy.sh` берёт из менеджера секретов (`secret tg-digest`; ключ Gemini — `secret agy`) — строки
`ИМЯ=значение`: `CLOUDFLARE_ACCOUNT_ID`, `CLOUDFLARE_API_TOKEN`, `BOT_TOKEN`, `TARGET_CHAT` (куда публиковать),
`OWNER_ID` (числовой id владельца — бот слушает только его), `GEMINI_MODEL`
(модели через запятую — откат на следующую при ошибке), `DEPLOY_HOST` (`claude@host` ВМ — юнит systemd пишется
под пользователя `claude` и каталог `/home/claude/tg-digest`; другой пользователь — поправьте юнит в `deploy.sh`),
`GEMINI_API_KEY`.
Без своего менеджера секретов замените строку `S=$(secret …)` в `deploy.sh` на чтение файла.

Выкладка — `./deploy.sh`; журнал на ВМ — `journalctl -u tg-digest`.

## Хранилище (R2 `tg-digest`)

`channels`, `background`, `tech` — источники трёх уровней; `last` — до чего прочитан каждый источник; `pool` —
собранное за сутки; `settings` — `{hours, paused, focus, alerts}`; `status` — итог прошлого выпуска;
`alerts` — объявленные тревоги за 48 ч; `update_id` — защита от повторной обработки команды.

## Команды бота (@your_bot)

Слушается только владельца (`OWNER_ID`), остальным молчит. В группе бот видит только команды;
переслать пост из канала, чтобы добавить его, — в личку боту.

`/list`, `/add @канал …`, `/add мир|тех @канал|URL-RSS …`, `/del @канал|URL …`, `/now`, `/preview`, `/status`,
`/pause`, `/resume`, `/schedule 9 14 20`, `/alerts on|off`, `/focus текст` (`/focus -` — сброс), `/ask вопрос`
(по постам за сутки), `/help`.
Опубликованное помечается в пуле только после успешной отправки: упал выпуск — следующий возьмёт те же материалы.
Закрытые каналы не добавляются — их лента без входа не открывается.

## Источники и пул

Три уровня: свои (`channels`, [мой]), мир (`background`, [мир]: ленты агентств и мировых СМИ, Telegram и RSS)
и технологии (`tech`, [тех]: технологические издания). Каждые 15 минут исполнитель собирает новое из всех
источников в `pool` (по странице на источник, своим — до двух). В часы выпуска Gemini пишет дайджест из
неопубликованного: «🌍 Главное в мире» из [мир], «🚀 Технологии и ИИ» из [тех], остальное — рубриками по своим
каналам. Без новых постов своих каналов выпуск не выходит. Опубликованное лежит в пуле сутки — по нему отвечает
`/ask`, без запросов к источникам.

## Экстренное 🚨

После каждого сбора лёгкая модель смотрит материалы за 2 часа и решает, есть ли чрезвычайное: война, массовый
теракт или катастрофа, ядерный инцидент, смена власти, обвал рынков. Порог высокий, продолжение идущих конфликтов
и заявления — не тревога. Нужны минимум два разных источника — это проверяет код, а не только модель; ссылки
берутся только из пула. Объявленное помнится 48 часов и не повторяется. В четверть часа выпуска проверки нет —
её сделает следующий сбор.
